Las fuentes jurídicas se gestionan en tu cuenta de OpenAI mediante el vector store existente (recomendado para este prototipo). Para conservar la configuración anterior, Khipu Legal sigue leyendo el archivo de configuración heredado `rimay_config.json` en el proyecto, su carpeta padre y Downloads. También puedes definir `OPENAI_VECTOR_STORE_ID` en `backend/.env`.

No se incluyen aquí copias de fuentes jurídicas ni se trata este directorio como un corpus legal oficial. Usa fuentes oficiales verificadas y registra su fecha/versión antes de presentar resultados como vigentes.
